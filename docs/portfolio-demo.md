## Что показывать заказчику

**Личный кабинет онлайн-школы**

Разработка интерфейса на Vue и интеграция со Strapi: вход ученика, назначенные курсы, список уроков, видео и скачивание материалов. Для владельца школы — управление контентом и доступами через CMS.

Публичное демо показывает интерфейс на тестовом курсе. Оно не использует материалы или базу заказчика и не заявляет коммерческие показатели проекта.

## Проверка

- `corepack pnpm test:demo` — вход, ошибочные данные, доступ к курсу/урокам/вложениям, выход, неизвестный материал, запрет записи и изоляция тестовых данных.
- `corepack pnpm build:demo` — TypeScript и сборка демонстрации.
- `corepack pnpm build:web` — обычная сборка для Strapi.
- Проверка реальной CMS требует отдельной локальной базы и настроенных прав. Тестовый адаптер не подтверждает серверную авторизацию.
- Старые `tests/unit/api` — интеграционные тесты предыдущей модели данных. Они требуют внешнюю CMS, содержат устаревшие импорты `entities/video` и не используются как проверка этой демонстрации.

## Размещение без расходов

Готов workflow `.github/workflows/portfolio-demo.yml`: тесты → сборка → публикация. В настройках репозитория выберите Pages → Source → GitHub Actions. После слияния PR в main публикация запускается автоматически; при необходимости используйте Run workflow на ветке main. На PR выполняется только сборка, без публикации.

Демонстрация добавлена в `main` через PR #3. Публикация статических файлов не меняет клиентский сервер.

При дальнейших изменениях проверять в браузере: вход кнопкой «Открыть демо», курс → список уроков → видео, скачивание чек-листа, выход; затем обновление прямой ссылки на урок. Проверить узкий экран и отсутствие горизонтальной прокрутки.

## Обновление демо

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm test:demo
corepack pnpm build:demo
```

После слияния изменений в main workflow опубликует только `apps/web/dist`. Исходники CMS, локальные `.env` и пользовательские загрузки не публикуются.

Демо-видео — созданный для примера 12-секундный ролик без звука; оно не является оригинальным учебным материалом заказчика. Обложки и чек-лист также созданы для демонстрации.
